# Mocha Muse landing page

A single-page landing site for Mocha Muse, hand-painted Arabic calligraphy on canvas.

Open `index.html` in a browser. It is one self-contained file: the artwork photos and logo are embedded, and the only outside requests are to Google Fonts.

To turn on the order buttons, fill in the `CONTACT` object near the top of the main script in `index.html` (WhatsApp number with country code, Instagram handle, or email).
