# Mocha Muse landing pages

Two design versions of a single-page landing site for Mocha Muse, hand-painted Arabic calligraphy on canvas.

- `index.html`: the marbled-paint version. A live coffee-and-cream marble background, a 3D ring of paintings, and expanding custom-order panels.
- `studio/index.html`: the light studio version. A spotlight hero that reveals a painting, bento tiles (including a colour try-out canvas), a draggable filmstrip of paintings and sticky custom-order steps.

Open either file in a browser. Each one is self-contained: the artwork photos and logo are embedded, and the only outside requests are to Google Fonts.

To turn on the order buttons, fill in the `CONTACT` object near the top of the main script in each file (WhatsApp number with country code, Instagram handle, or email).
